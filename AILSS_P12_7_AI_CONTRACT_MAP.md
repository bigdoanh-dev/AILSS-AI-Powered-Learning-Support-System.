# AILSS P12.7 AI contract map

| Operation   | Method/path                                       | Role/ownership                                                     | Request and guards                                                                                                                    | Response, state, side effect                                                                                                                                                                                                 |
| ----------- | ------------------------------------------------- | ------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| AI-01       | `POST /api/v1/ai/quiz-jobs`                       | Verified Lecturer; owned extracted Document and owned Course/Class | Exact `documentId`, `targetType`, `targetId`, `questionCount` 1–50, unique canonical `questionTypes`, `difficulty`; `Idempotency-Key` | `202` Quiz Generation job in `QUEUED`; emits `ai.quiz.generate.v1`; quota reserved. Retry with identical key/body replays.                                                                                                   |
| AI-02       | `GET /api/v1/ai/jobs/{jobId}`                     | Job owner                                                          | UUID path                                                                                                                             | Safe job DTO and canonical version/state. Quiz Generation states: `QUEUED`, `PROCESSING`, `VALIDATING`, `AI_DRAFT`, `FAILED`, `APPROVED`, `CANCELLED`; it never uses `COMPLETED`.                                            |
| AI-03       | `GET /api/v1/ai/jobs`                             | Owner projection                                                   | Required `state`, `month`; bounded `limit` ≤50; opaque `cursor`                                                                       | State/month page and opaque `nextCursor`. There is no safe “all jobs” query.                                                                                                                                                 |
| AI-04       | `GET /api/v1/ai/jobs/{jobId}/drafts`              | Job owner                                                          | UUID path                                                                                                                             | Stored generated draft(s), including draft v1, validation state and `objective-v1` content. No provider response.                                                                                                            |
| AI-05       | `POST /api/v1/ai/drafts/{draftId}/approve`        | Verified owner Lecturer                                            | Exact `{reviewedDraft}`; `Idempotency-Key`; current boundary `If-Match: "v1"`                                                         | Approved draft v2 and exactly one Assessment Quiz v1 `DRAFT` through INT-ASMT-01. It never publishes the Quiz.                                                                                                               |
| AI-06       | `POST /api/v1/ai/jobs/{jobId}/cancel`             | Job owner                                                          | UUID path; Web supplies stable command identity                                                                                       | Canonical `CANCELLED` when still cancellable; terminal FAILED/CANCELLED is idempotent; `AI_DRAFT` cannot be cancelled.                                                                                                       |
| AI-07       | `POST /api/v1/ai/documents/upload-intents`        | Verified Lecturer                                                  | Filename, supported MIME, 1–25 MiB, SHA-256; `Idempotency-Key`                                                                        | Ephemeral direct-upload URL and object key for `UPLOAD_PENDING`. These values must remain memory-only.                                                                                                                       |
| AI-08       | `POST /api/v1/ai/documents/{documentId}/complete` | Document owner                                                     | Exact object key, byte count, MIME, SHA-256; `Idempotency-Key`                                                                        | `202`, document `EXTRACTION_QUEUED`; emits `ai.document.extract.v1`.                                                                                                                                                         |
| AI-09       | `GET /api/v1/ai/documents/{documentId}`           | Document owner                                                     | UUID path                                                                                                                             | Safe Document DTO. States: `UPLOAD_PENDING`, `EXTRACTION_QUEUED`, `EXTRACTING`, `EXTRACTED`, `FAILED`, `QUARANTINED`. Document Extraction's internal job may reach `COMPLETED`; readiness is the Document `EXTRACTED` state. |
| AI-10       | `GET /api/v1/ai/usage`                            | Verified Lecturer                                                  | None                                                                                                                                  | Canonical daily `limit`, `reserved`, `consumed`, `remaining`; no provider tokens or monetary cost.                                                                                                                           |
| INT-ASMT-01 | `POST /internal/v1/ai-drafts/{id}/import`         | AI → Assessment                                                    | Service JWS, signed Actor Context, purpose allowlist, 2 s fail-closed/idempotent                                                      | Imports approved draft v2 as Assessment Quiz v1 `DRAFT`; no event and no publication.                                                                                                                                        |

Relevant Assessment boundary: ASM-01 creates Lecturer-owned drafts, ASM-02 returns owner authoring detail, ASM-03 versions DRAFT edits immutably, ASM-04 explicitly publishes, and ASM-05 lists only a selected target. AI approval stops before ASM-04.

Errors surfaced as safe product states include invalid/expired cursor, Document not ready/not owned, target not owned/unavailable, quota exhausted, job/draft not found, cancellation/version conflict, invalid reviewed objective, stale `If-Match`, Assessment dependency unavailable and ambiguous 503/lost response. Server validation and ownership remain authoritative.
